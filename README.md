# 💼 Eshwar Kumar — Software Engineer Portfolio

Welcome to the official repository for **Eshwar Kumar's Personal Portfolio Website**. Designed with a modern, responsive glassmorphic UI, rich interactive micro-animations, dynamic canvas backgrounds, and a direct contact system.

---

## 🚀 Live Demo & Overview

- **Author:** Eshwar Kumar (Computer Science Scholar at Sukkur IBA University)
- **Role:** Software Engineer | Java, Python, C++ & Full-Stack Developer
- **Website Features:**
  - 🎨 **Modern Dark / Glassmorphic UI:** Built with custom vanilla CSS and fluid typography.
  - ✨ **Interactive Particle Canvas:** Ambient animated background reacting to user movement.
  - 💻 **Project Showcase & Deep-Dive Modals:** Interactive previews and modal walkthroughs for featured projects.
  - 📬 **Functional Direct Contact System:** Connected via FormSubmit with full sender attribution and 1-click Gmail compose fallback.
  - 📄 **Interactive Resume Preview:** In-browser modal viewer with quick download options.

---

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, CSS3 (Custom Design System, Glassmorphism, CSS Grid & Flexbox), Vanilla JavaScript (ES6+)
- **Typography:** Outfit, Plus Jakarta Sans, JetBrains Mono (Google Fonts)
- **Icons:** Font Awesome 6
- **Form Handling:** FormSubmit API & Direct Mail Integration
- **Server:** Static HTTP / GitHub Pages Compatible

## 💻 Running Locally

You can run this project locally using Python's built-in web server or any static file server:

```bash
# Clone the repository
git clone https://github.com/Eshwarmatani/Protfolio.git

# Navigate to the project directory
cd Protfolio

# Start a local server (Python)
python -m http.server 3000
```

Then open your browser and visit: **`http://localhost:3000`**
